# FullStack Web App – ArcGIS API geodata Integration & Visualization

Web Data visualization about criminal activity and cop presence in Bogota,
using official geodata from ArcGIS API service.

## Technologies

- Python
    - pip, venv, jupyter
- Javascript

## Stack

### Backend

- FastAPI
- GeoPandas
- Requests

### Frontend

- Folium
- Bootsrap CDN
- Chart.JS CDN
